# 小米图片分类整理

把小米手机备份到电脑里的图片按规则分类整理的 Windows 小工具。

支持两种来源：直接读 USB 连接的小米手机（MTP），或者整理已经备份在硬盘上的目录。照片按拍摄地点和时间归档，截图按来源应用归档，文件名统一改成 `YYYYMMDD_HHMMSS`。

## 用

双击 `dist/小米图片分类整理.exe` 就能跑，单文件，离线地理编码数据也打进去了，不用联网。

从源码跑：

```
pip install -r requirements.txt
python app.py
```

打开后左边选「传输备份」（从手机导入）或「图片分类」（整理本地目录），设好目标目录，选复制还是移动，点开始就行。性能那栏默认 1 线程，保守点不卡机器，想快点可以调到 2 或 4。

## 打包

```
pyinstaller build.spec --noconfirm
```

产物在 `dist/小米图片分类整理.exe`。

## 怎么分类的

照片和截图的区分主要看目录和文件名：在 `Screenshots` 目录下、带 `Screenshot_` 前缀或 `com.xxx` 包名的算截图；带 EXIF 相机型号或 GPS 的算照片。

照片有 GPS 就离线转成省-市（用 fast-geocn，不联网），放到 `照片/省-市/年/月/` 下面。截图从包名映射出应用名（`com.tencent.mm` → 微信），放到 `截图/应用名/`。没 GPS 的照片归到「未知地区」，认不出来源的归到「其他图片」。

重名自动加 `_2`、`_3`，长截图保留 `_long` 后缀。原始文件全程只读不删，复制完校验大小，单文件出错不影响整体，出问题的留在 `_暂存区/`。

目录大概长这样：

```
目标目录/
├── 照片/
│   └── 广东省-深圳市/2025年/2025-07月/20250708_091011.jpg
├── 截图/
│   └── 微信/20240115_103045.jpg
└── _暂存区/
```

## 配置

`config.py` 里能改扫描目录、图片后缀、地理编码坐标系。如果发现照片定位偏移（有些机型写的是 GCJ-02），把环境变量 `PHOTOCAT_GEO_CRS` 设成 `gcj02`。

## 结构

```
app.py              Flask 入口，路由和流水线调度
config.py           配置
core/               mtp_device / exif_reader / geocoder / classifier / pipeline 等
build.spec          PyInstaller 打包配置
templates/ static/  前端页面
```
