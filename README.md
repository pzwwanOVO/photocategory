# NestPics

把手机（USB MTP 模式）备份到电脑的图片进行系统化分类整理的 Windows 桌面应用。
自动完成：检测设备 → 授权传输 → 识别图片目录 → 复制图片 → 按元数据/文件名规则分类 → 重命名为统一时间格式 → 输出统计。

提供打包好的单文件 exe，双击即用；也可用源码运行。数据全程不离设备。

## 特性

- 原生桌面窗口：pywebview（Edge WebView2），Win11 Fluent 风格无边框窗口，非浏览器
- USB/MTP 自动检测：Windows Shell COM 识别便携设备，无需 ADB/驱动；长时间未检测到会停止轮询并提示重试
- 机型目录识别：根据设备名推断品牌（小米/三星/华为/OPPO/vivo 等 16 种），自动定位 DCIM、Pictures 等图片目录并预勾选
- 多目录扫描：识别区与设备浏览器均支持复选框多选，可同时备份多个目录
- 本地目录分类：直接整理已备份到电脑的目录（如 `D:\photo`），支持复制/移动两种模式
- 多线程并发：本地分类可调线程数（1/2/4），默认 1 线程保守模式；MTP 模式单线程（COM 绑定）
- 照片 vs 截图智能识别：综合目录、文件名前缀、包名、EXIF 相机型号/GPS 多级判据
- 照片分类：EXIF GPS → 离线逆地理编码（省-市）→ `照片/<省-市>/<YYYY年>/<YYYY-MM月>/`
- 截图分类：从文件名解析应用包名（如 `com.tencent.mm`）→ 映射为应用中文名 → `截图/<应用名>/`
- 统一命名：`YYYYMMDD_HHMMSS.ext`，重名自动追加 `_2/_3`，长截图保留 `_long`
- 安全无损：复制后大小校验；原始设备文件只读不删；失败文件保留在暂存区
- 实时进度：进度条 + 大号百分比 + 当前文件 + 照片/截图/失败计数 + 完成统计
- 离线地理编码：基于 fast-geocn，支持 WGS-84/GCJ-02/BD-09 坐标系，无需 API Key
- 深色模式：浅色/深色/跟随系统三种主题，CSS 变量平滑切换
- 中英双语：界面语言可切换，首次启动有引导页选择语言
- 单实例运行：重复启动会激活已有窗口而非开新进程
- 配置隔离：运行时设置存放在 `%APPDATA%\PhotoCategory\`，不污染 exe 同级目录

## 环境要求

- Windows 10/11 x64（WebView2 运行时，Win11 自带）
- 手机通过 USB 连接，并在手机上选择「传输文件 / USB 传输」模式
- 源码运行需 Python 3.11+（开发基于 3.13）

## 直接使用（推荐）

下载 `dist/NestPics.exe`，双击运行即可（单文件，约 41 MB，含离线地理编码数据）。

## 源码运行

```bash
cd d:\apk\photocategory
python -m pip install -r requirements.txt
python app.py
```

将打开原生应用窗口。

## 打包为 exe

```bash
pyinstaller build.spec --noconfirm
```

输出：`dist/NestPics.exe`

## 操作流程

1. 双击 exe（或 `python app.py`）打开应用，首次启动选择语言
2. 左侧选择「传输备份」（从手机导入）或「图片分类」（整理本地目录，如 `D:\photo`）
3. 传输备份模式：USB 连接手机 → 手机端选择传输图片 → 自动识别品牌和图片目录（DCIM/Pictures 等）→ 勾选要备份的目录 → 设置备份位置 → 开始备份
4. 图片分类模式：选择本地目录 → 设置目标位置 → 选择操作方式（复制/移动）与线程数 → 开始整理
5. 观察实时进度，完成后查看分类统计（照片按地区、截图按应用、失败列表）
6. 备份完成后可直接跳转分类，将备份目录作为分类源继续整理

## 分类规则

### 照片 vs 截图判定（按优先级）

1. 目录含 `Screenshots` / `SCREEN_CAP` → 截图
2. 文件名前缀 `Screenshot_` / `LongScreenshot_` / `截屏` → 截图
3. 文件名含包名 `com.xxx.xxx` → 截图
4. EXIF 有相机型号(Make/Model) 或 GPS → 照片
5. 兜底：常见照片前缀(`IMG_`/`DSC`) → 照片；否则默认照片

### 目录结构

```
目标目录/
├── 照片/
│   ├── 广东省-深圳市/
│   │   └── 2023年/2023-07月/20230708_091011.jpg
│   └── 未知地区/              # 无 GPS 的照片
│       └── 2022年/2022-11月/20221111_080000.jpg
├── 截图/
│   ├── 微信/20240115_103045.jpg
│   ├── 抖音/20240320_080000.jpg
│   └── 未识别应用/            # 截图文件名无包名
└── _暂存区/                   # 分类失败/异常文件保留于此
```

## 配置

`config.py` 可调整：扫描目录、图片后缀、地理编码坐标系（`GEO_SOURCE_CRS`：`wgs84`/`gcj02`/`bd09`）、复制超时等。

> 若照片定位有明显偏移（中国部分机型写入 GCJ-02），可将环境变量 `PHOTOCAT_GEO_CRS` 设为 `gcj02`。

## 项目结构

```
app.py              # Flask 入口：路由 + SocketIO + 流水线调度
config.py           # 配置
core/
├── mtp_device.py   # MTP 设备检测/枚举/复制（Shell COM）+ LocalSource
├── phone_dirs.py   # 手机品牌识别 + 图片目录映射
├── exif_reader.py  # EXIF 提取（GPS、时间、型号）
├── geocoder.py     # 离线逆地理编码（fast-geocn）
├── app_names.py    # 包名→应用名映射表
├── classifier.py   # 分类决策与统一命名
├── file_ops.py     # 校验/冲突重命名/移动归位
└── pipeline.py     # 流水线编排 + 进度回调
templates/index.html, static/css, static/js   # 前端
```

## 安全与错误处理

- 原始设备文件全程只读，绝不删除
- 复制后立即大小校验，失败重试 2 次
- 单文件异常隔离，不中断整体流程，记录到失败列表
- 失败文件保留在 `_暂存区/` 供人工处理
